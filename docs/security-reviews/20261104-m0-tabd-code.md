## Findings
| # | Sev | Area | Finding | Disposition | Fix / reason | Regression test |
|---|---|---|---|---|---|---|
| 2a-1 | Medium | Path policy | `/opt/homebrew` (user-writable, holds `sbx`) and other host binary or dev-tool dirs were claimable. A tab could rewrite `sbx`, and tabd would execute it within 60 s. | Fixed (46a99aa) | Refuse `/opt/homebrew`, `/usr/local`, `/Applications`, the sbx/docker realpaths and their dirs, `~/bin`, `~/.cargo`, `~/.nvm`, … and agent config files. | `unit.test.ts` "validate: workspace paths" |
| 2a-2 | Medium | Fence lifecycle | Monitoring stopped when the last channel closed while the VM kept running; tabs that were started but never connected were not stopped on exit; no reconciliation after a crash; a throw in the timer crashed the process. | Fixed (46a99aa) | Monitor while the sandbox runs (from `ensureRunning`). Own every started, connected or adopted tab and stop them on exit. Leases plus startup reconciliation. try/catch → quarantine. `connect` refuses stopped sandboxes. | `supervisor.test.ts` (drift → quarantine; client gone stops never-connected tabs; connect needs running) |
| 2a-3 | Medium | Fence parse | An unknown `applies_to` form was silently ignored. | Fixed (46a99aa) | Fails closed. | `unit.test.ts` "fence: fails closed on unknown shapes" |
| 2a-4 | Low | Fetch provenance | `seclab fetch macos` took any successful run (any branch or event); the checksum came from the same artifact. | Fixed (df201de); residual accepted | Only main/push runs (explicit override for own-branch builds); run metadata re-checked; build-info vs upstream.lock and head SHA. Attestations are not used (they need GHEC for private repos); add them if the repo goes public. | — |
| 2b-1 | **High** | Routing | A `file://` folder loads in a local window before the Tab Manager reroutes it. `.code-workspace` and multi-root windows were never routed, so a previously trusted folder whose `.git/config` was planted by its tab could run git on the host. | **Partially fixed; residual open (HIGH)** | Local multi-root, workspace-file and non-file windows are now **closed**. A declined or failed routing closes the folder. Remaining race for previously trusted single folders: fix proposed as [ADR route-folder-opens-in-main](../adr/20261104-route-folder-opens-in-main.md) (core patch), pending approval. | TODO: editor-level test once the patch exists |
| 2b-2 | Medium | Path policy | Denylist by default; `allowedRoots` was optional. | Fixed | tabd refuses claims without allowed roots, and refuses roots that are `/`, `/Users`, `/home` or `$HOME`. The Tab Manager asks for a projects folder on first claim. | `unit.test.ts` (no roots / too broad) |
| 2b-3 | Low | Harness | The fsmonitor fixture left an armed `.git/config` in the host work dir. | Fixed | Cleanup removes `.git`. | — |
| (new, self) | **High** | Extension placement | A gallery extension declaring `extensionKind: ["ui"]` would be **installed and run on the host** in a tab window. Product overrides were per-ID only, and the user setting took precedence. | Fixed (patch 0002 + product.jq) | `extensionKind["*"] = workspace`; user `remote.extensionKind` ignored; ui only for generated built-ins and the Tab Manager. [ADR](../adr/20261104-extensionkind-default-workspace.md) | TODO: editor-level Level B check (`check-evidence.ts`: rogue ui extension has remoteName=seclab) |
