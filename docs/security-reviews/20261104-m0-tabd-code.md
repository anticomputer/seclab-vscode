## Round 5 (`8d34b5d..e48f019`: patches 0002 v3/0004, pre-mount secret scanning)
Verdicts: 4-1 fixed. Upstream already refuses to install over a system-extension ID, so the chain was also blocked there. Residual (defence in depth): the second `toExtensionDescription` in `workbench/services/extensions/common/extensions.ts:580-595` still spread the manifest last. **Fixed**: patch 0004 now covers both sites. The suggested invariant (every `ui` ID ships as a built-in) already holds by construction: `product.jq` generates the allowlist from the checkout's own built-in manifests. 4-2 fixed.

| # | Sev | Area | Finding | Disposition | Fix / reason | Regression test |

| S1 | Medium | Scanner | A tab could stuff the workspace so one pass's report overflowed the 4 MiB cap.
